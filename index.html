    Tournaments

    Round robins, gauntlets and matches, several games at once. Every pairing plays the same openings, with colours reversed.

    • Any clock, depth or node limit
    • Win and draw adjudication
    • Live graphs of eval, speed, depth, time and CPU
    • Full PGN and UCI logs

    Live boards

    Depth, speed, hash and clocks for both engines, on every board.

    Engine registry

    Install engines from inside the app. It picks the right build for your CPU and tells you when there's an update.

    • CCRL ratings and a GitHub trust score
    • Profiles for different settings
    • Crashed engines never linger

    Opening books

    Import Polyglot, PGN or EPD, download one, or have your engines build one together. A line is kept only if every engine agrees.

    fastchess and SPRT

    Start SPRT tests from any terminal and watch them live, with LLR, Elo and LOS as games finish.
